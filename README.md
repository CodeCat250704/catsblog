## 创作由来

我们一开始就是想折腾一个**视觉上有apple液态玻璃效果**的博客。受够了那种土里土气的博客，所以联合了Cat(css html),Gqun(css html),**DeepSeek**（AI）(js)创造了它。。

为了方便修改，节约时间。我们使用了最原始的 HTML + CSS + JavaScript 。
为了达到“蒙了一层磨砂玻璃”的质感，我们对以下几点做了创新：

1. 我们放弃了沉重的 UI 框架，全部**手写**。
2. **玻璃质感**：见下文。
3. 3D视图还在开发，我们力争实现**裸眼3D效果**

## 教大家同款液态玻璃

**因为开发者语文不太好，所以我们使用豆包对代码注释进行润色，确保大家都看得懂**


```css
.glass-panel {
    
    /* --- 1. 颜色与材质 --- */
    /* 极低透明度的纯白背景。0.1 ~ 0.3 是经典的玻璃值（没有也行
       数字越小，背后的景色透得越清晰；
       数字越大，玻璃越像磨砂塑料。 */
    background: rgba(255, 255, 255, 0.15); 
    /* 采用全透明也不错 */
    background: transparent;
    

    /* --- 2. 动态背景模糊 (磨砂质感) --- */
    /* 
       高斯模糊： 20px 
       【注意】：必须配合 background: rgba() 使用
       （background: transparent;我们没有展开测试，下一代发布时在告诉大家）
       如果没有半透明底，模糊是看不见的。 */
    backdrop-filter: blur(20px);
    -webkit-backdrop-filter: blur(20px); /* 兼容老版本的 Safari 和 Chrome */

    /* --- 3. 边缘与高光  --- */
    /* 白色的实线边框。
       这是区分玻璃与背景的“物理边缘”，让玻璃看起来有轮廓。 */
    border: 1px solid rgb(255, 255, 255);
    

    /* --- 4. 厚度与悬浮 --- */
    /* 外阴影：让玻璃面板看起来从背景上浮
       此条注释由AI生成：内阴影：在边框内侧加一层极细的高光反射线。
       这两层阴影叠加，让扁平的 2D 平面看起来有了“厚度”和“折射感”。 */
    box-shadow: 
        0 8px 32px 0 rgba(31, 38, 135, 0.08),   /* 外 */
        inset 0 0 0 1px rgba(255, 255, 255, 0.1); /* 内 */
    

    /* --- 5. 水滴轮廓--- */
    /* 大圆角 14px。 */
    border-radius: 14px;
    

    /* --- 6. 体感反馈) --- */
    /* 鼠标悬浮时，半透明背景稍微变实一点点（从 0.15 变成 0.25），
       边框变亮，阴影加深。
       让用户感觉鼠标“碰”到了液态玻璃的表面。
       后续我们将研究水的波纹，力争加入。 */
    transition: transform 0.3s ease, box-shadow 0.3s ease, background 0.3s ease;
}

.glass-panel:hover {
    background: rgba(255, 255, 255, 0.25);
    border-color: rgba(255, 255, 255, 0.8);
    box-shadow: 0 12px 40px rgba(31, 38, 135, 0.15), inset 0 0 0 1px rgba(255, 255, 255, 0.3);
}

```
## 功能点

如果你只是觉得好看，那你就低估它了。
我个人最喜欢的是这几点：

1.  **纯静态文件数据库**：
    我建了一个 `/book/` 文件夹来当“数据库”。
    发文章就是往 `/book/` 里放文件夹，文件夹里面放 
    · `meta.json` 数据
    · `md` 文件
    · `/picture/` 文件夹
    · `/headpicture/` 封面图。
    **优点**：
    1. 不折腾服务器，
    2. 无迁移成本。
2.  **全功能沉浸式播放器**：
    很多非音乐站的音乐播放器只能“点击播放”。
    我们直接用**Web Audio API** 。 **“重低音增强”** 和 **“杜比全景声空间环绕”** 的音效处理是创新点，尽管**JS实现是AI写的**。
3.  **数据全部本地化，自带反调试防御**：
    为了防止别人轻易扒源码，项目策划人**Cat**联合**Deep Seek**手写了一套**防 防 F12和Ctrl+Shift+I 的机制**，并且用 `SourceMap` 做了代码混淆转移。懂行的人打开控制台，看到的代码会是一堆乱码和假逻辑。
    反爬代码存储位置见下文**项目整体结构**。

## 项目整体结构
```txt
/
├── index.html                        # 【入口】博客的主 HTML 
│
├── background.jpeg                   # 【背景】全局唯一动态背景图
│
├── CNAME                             # 【部署】GitHub Pages 自定义域名绑定文件
│
├── push.bat                          # 【工具】一键推送脚本：双击即可自动执行 git add, commit, push
│
├── /assets/                          # 【公共资源】
│   ├── common.css                    # 【样式】全局通用的 CSS
│   ├── common.js                     # 【逻辑】加载 modules 里的各个页面
│   └── security.js                   # 【安全】防 F12 快捷键、防右键打开控制台、抗调试爆破代码
│
├── /modules/                         # 【功能模块】每个文件夹都是一个独立的单页应用子页面全部由script.js（AI），style.css，index.html组成
│   ├── /home/                        # 【首页】轮播图、公告、历史发布、全功能音乐播放器
│   │   ├── index.html
│   │   ├── style.css
│   │   └── script.js
│   ├── /categories/                  # 【分类】三栏布局：左侧分类切换、中间文章列表、右侧阅读预览
│   ├── /collection/                  # 【收藏】结构与分类一致，读取 favorites 数据
│   ├── /notice/                      # 【通知】单栏大卡片，展示系统公告与动态
│   ├── /co-create/                   # 【共创】大卡片，以名片形式展示文章/图片/创作贡献者
│   ├── /submit/                      # 【投稿】投稿规范说明、邮件标准模板以及 10 大主流邮箱一键直达
│   ├── /about/                       # 【关于】介绍博客、博主与技术栈
│   └── /settings/                    # 【设置】描边无填充开关、毛玻璃模糊度滑块调节
│
├── /book/                            # 【核心数据仓库】纯静态，完全通过 JSON 和 MD 驱动
│   ├── meta.json                     # 【总索引】全站数据登记表 (公告、音乐、文章、收藏的聚合)
│   │
│   ├── /music/                       # 【音频库】存放 mp3 音乐文件（播放器自动读取）
│   │
│   ├── /home/                        # 【首页轮播图】存放首页大轮播的背景图与素材
│   │   └── /1/                       # 对应文章 ID 的文件夹
│   │       ├── /headpicture/         # 【封面图】轮播图上展示的大图
│   │       │   └── cover.jpg
│   │       ├── /md/                  # 【正文】MD 格式的文章正文
│   │       └── /picture/             # 【插图】文章内嵌图片
│   │
│   └── /information/                 # 【信息存储】静态页面所需的数据层（通知、共创等）
│       ├── notice.json               # 通知数据
│       └── co-create.json            # 共创数据
│
└── /_fake_source/                    # 【安全伪装】防破解映射源
    └── fake_common.js                 # 伪代码：真实逻辑被替换为乱码和假逻辑，误导调试者

```
